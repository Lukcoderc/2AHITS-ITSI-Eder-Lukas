## Linux VM installieren

1. Zip Datei mit Vm von USB Stick auf Desktop speicher.
2. Zip Datei in einen Ordner entpacken.
3. In Vmware auf "Open a Virtual Maschine" drücken und die entpackte Datei auswählen.
4. Bei Kali Linux das Passwort und Benutzer "kali" eingeben. Und bei Metasploitable Benutzer und Passwort "msfadmin" eingeben.

## VSCode Installieren

Installieren:
```sh 
wget -O vscode.deb "https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64"
```

```sh
sudo apt install ./vscode.deb
```

Version kontrollieren:

```sh
code --version
```

Starten im aktuellen Verzeichnis:

```sh
code ./
```
