## WC

### -m → zählt Zeichen
Beispiel:
```sh
wc -m klassenkassa.csv
```
Ausgabe:
```
4377 klassenkassa.csv
```
### -l → zählt Zeilen
Beispiel:
```sh
wc -l klassenkassa.csv
```
Ausgabe:
```
146 klassenkassa.csv
```
###  -L → gibt die Länge der längsten Zeile aus
Beispiel:
```sh
wc -L klassenkassa.csv
```
Ausgabe:
```sh
36 klassenkassa.csv
```
### -w → zählt Wörter
Beispiel:
```sh
wc -w klassenkassa.csv
```
Ausgabe:
```
146 klassenkassa.csv
```


Befehl:
```sh
echo eins zwei drei | wc - klassenkassa.csv
```

Ausgabe:
```sh
  1       3      15 -
146     146    4384 klassenkassa.csv
147     149    4399 total
```

Der wc Befehl listet zuerst die Werte des mit echo übermitelten Wortes auf dann die Werte der klassenkassa csv. In der letzten Zeile Zählt er alle Werte zusammen.



## CUT

Cut schneidet bestimmte Teile aus einem Text heraus und gibt sie aus.


Beispiel:
```sh
cut -c 5 klassenkassa.csv
```

Mit `-c` kann man Zeichen auswählen die man ausschneiden möchte.

Mit `-f` wählt man Felder (Spalten) aus, getrennt durch ein Trennzeichen:

### Varianten der `-f` Option


| Befehl | Bedeutung |
|---|---|
| `-f 2` | nur Feld 2 |
| `-f 1,3` | Felder 1 und 3 |
| `-f 2-4` | Felder 2 bis 4 |
| `-f -3` | Felder 1 bis 3 |
| `-f 3-` | Feld 3 bis Ende |

Beispiel:
```sh
cut -d ',' -f 2 klassenkassa.csv
```

## Übung: Werkstatt Summe

```sh
grep "Werkstatt" klassenkassa.csv | cut -d ',' -f 2 | paste -sd '+'
```

1. `grep` filtert Zeilen mit „Werkstatt"
2. `cut -d ',' -f 2` extrahiert die Beträge
3. `paste -sd '+'` fügt sie zu einer Zeile zusammen
