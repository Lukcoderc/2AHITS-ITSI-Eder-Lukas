## 1. XXD

Der Befehl `xxd` sorgt dafür das eingegebene Normale Buchstaben in Asc Code angezeigt werden.

bsp:
```sh
echo "a" | xxd
00000000: 610a                                     a.
```

### Die Optionen `-n -r -p` 

-n sorgt dafür das echo keinen Zeilenumbruch mehr dranhängt.

-p sorgt dafür das xxd nur mehr der Ascii Code angezeigt wird und nicht mehr die Stelle wo es liegt in Hex und was es in Normalen Zeichen ist.

-r sorgt dafür das xxd rückwärts funktionert also aus Ascci normale Zeichen macht.


bsp mit Emojis:

```sh
echo -n "😃" | xxd -p
f09f9883
```


```sh
echo -n "f09f9883" | xxd -r -p
😃
```
